## Summary

Akash's third community livestream (July 2020, pre-mainnet), hosted by Greg Osuri with Jack Zampolin. Updates: the Akashian Challenge phase 2 testnet launched successfully (phase 1 validated the decentralized launch with validators; phase 2 tests on-chain DEX/marketplace functionality; phase 3 will be a full dry run incentivizing real applications — open-source apps, oracles, DeFi frontends). A misconfiguration hiccup was quickly fixed, drawing on lessons from Cosmos's Game of Zones. Partnerships announced: Lunie wallet (staking/delegation/governance UI for AKT), GRG Capital, and a Chinese community launch whose first AMA drew over 5,000 attendees — Greg notes China is "a gigantic market for machine learning" where Akash "would be a great addition to their capacity." The technical centerpiece: the migration from the old Tendermint codebase to Cosmos SDK reached core feature parity, and Jack demos the full flow locally — a kind (Kubernetes-in-Docker) cluster with nginx ingress as the provider side, chain bootstrap, provider creation, an SDL deployment file posted on-chain (only settlement info stored on-chain for privacy), bid/lease matching, and a personal website served from the cluster. Next week's phase 2 stage, "Chaos is a Ladder," is a throughput free-for-all scored on lease hours and lease counts. Q&A covers community-built analytics tools (APIs open, protobuf migration coming for JS libraries), a referral program, and developer incentives: 5% of the network is being given away to developers (2% in the prior testnet, 3% in this one) as the bootstrapping mechanism. Ends with a Supermini hardware giveaway draw.

### [crypto-depin] Giving away 5% of the network to developers as the bootstrap mechanism
> "For our developer incentives, we're giving away five percent of the network — last testnet we did was two percent, this testnet is three percent — so we are very committed to ensuring the developers [are] incentivized early. That will be our bootstrapping mechanism before the value of the network actually occurs in the token."
> — [00:29:41](https://www.youtube.com/watch?v=shFtDmsCGNc&t=1781s)

**Context:** Closing remark on how Akash planned to bootstrap supply and demand before mainnet token utility existed.
