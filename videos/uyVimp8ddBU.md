## Summary

An Akash Twitter Spaces hosted by community lead Adam Wozny with Babylon co-founder David Tse (Stanford professor, blockchain consensus researcher) and Greg Osuri, recorded the day of a hyped DOJ "crypto enforcement" announcement (which turned out to be the obscure exchange Bitzlato — running gag throughout). Tse explains Babylon: bringing Bitcoin's proof-of-work security to proof-of-stake chains via checkpointing/timestamping (hashing PoS blocks onto Bitcoin), with concrete use cases like shrinking Cosmos's 21-day unbonding to ~a day. Greg frames this as "composable security" — chains choosing security components a la carte and paying more to secure higher-value assets — and predicts it will come to Cosmos broadly. He announces Akash's newly open-sourced contribution process (SIGs/working groups/user groups modeled on Kubernetes, with on-chain-posted minutes), noting nine external contributors joined in the first week and that external contributors now outnumber Overclock staff, and argues true decentralization must peel down to who writes the code and controls the website/communications. He resists labeling Akash a DAO ("biases automatically take precedence"), preferring granular properties like permissionless and non-custodial. On collaboration: Akash's testnet blocks already receive Bitcoin timestamps via IBC; Greg sees a future where Akash partially borrows Bitcoin security to get better price-performance than its inflationary security budget, with token holders choosing the mix. Looking six months out: Babylon's public testnet with 5-10 chains, and Akash "going into GPUs" — possibly even securing Bitcoin with high-end chips.

## Predictions & Notable Claims

### [other] Composable, priced-by-value security is coming to Cosmos
> "You can compose different chains together to form different levels of security, different sources of security... I think we're gonna see that sort of composability happen, and you pay higher price for securing higher valuable items, just like in the real world. I think that's going to come to Cosmos as well."
> — [00:05:00](https://www.youtube.com/watch?v=uyVimp8ddBU&t=300s)

**Context:** Reacting to Babylon's "security as a service" model; Greg calls composable security an emerging concept unique to Cosmos's modularity.

### [other] Decentralization must peel down to code, website, and communications control
> "Ultimately it comes down to who's actually writing the code, who's actually controlling the website, who's actually controlling the communications — those become the attack vectors. So if you can sufficiently decentralize these layers, you will be able to create a much, much better system when it comes to resiliency."
> — [00:21:38](https://www.youtube.com/watch?v=uyVimp8ddBU&t=1298s)

**Context:** Justifying Akash's newly opened contribution process (SIGs/working groups modeled on Kubernetes); he describes decentralization as an onion — consensus, then governance, then development — where "peeling enough layers" reveals the cracks.

### [other] Akash will borrow Bitcoin security for better price-performance
> "Our security budget... comes from inflationary tokens... we pay higher price for lower security. But if I can optimize the security budget to have much better price for performance by borrowing Bitcoin security, I think we'll be a lot better and a lot more secure chain. So I see a future where we can borrow Bitcoin security and pay relatively less than what we're paying right now."
> — [00:31:39](https://www.youtube.com/watch?v=uyVimp8ddBU&t=1899s)

**Context:** On Akash-Babylon collaboration; he proposes starting with partial borrowed security and letting token holders tune how much security to buy from where, ideally in real time.

### [gpu-economics] GPUs coming to Akash within six months — maybe even to secure Bitcoin
> "As we're sort of like going into GPUs in the next six months for Akash, I think it'll be amazing how we can further actually maybe even provide security to Bitcoin using some of these high-end chips we'll be tapping into."
> — [00:36:01](https://www.youtube.com/watch?v=uyVimp8ddBU&t=2161s)

**Context:** Crystal-ball question on the next six months (January 2023); Akash's GPU mainnet did ship later in 2023. The Bitcoin-securing-GPUs idea was floated as a mutual Babylon-Akash experiment.
