## Summary

This is the same recorded AMA with Bittrex Global's Chris Zinke that was published as BlfmFCEycW0 (May 28, 2021) — the content is word-for-word identical, re-uploaded ~4 weeks later without the first ~4.5 minutes of preamble. Greg covers: his AngelHack background (150,000 developers, Firebase launch) and early Kubernetes work; how Overclock Labs "stumbled into" blockchain while building an edge-optimized cloud; the thesis of tapping 8.2 million underutilized data centers via a permissionless, user-priced marketplace; the "d-cloud" umbrella (Akash compute + Sia storage + Handshake DNS + NuCypher keys) with Akash as gateway; Akash as the only live reputation-based decentralized compute platform able to run anything AWS runs (vs. Golem/Sonm/iExec verifiable compute); DeFi front-end/middleware hosting (Serum's UI on Akash) at a third the cost of running Ethereum full nodes on centralized cloud; AKT tokenomics (389M max supply, decaying inflation to fee-sharing with up to 20% of network revenue to stakers); and the roadmap — persistent storage, then a multi-tenancy GPU marketplace anticipating Ethereum's merge stranding miner GPUs, plus cutting deploy time from 90 minutes to one minute. He again dismisses "Supermini" hype as an experimental GPU cluster and candidly says no one in d-web has product-market fit yet. Stats cited: 55 unique applications, 17x usage growth in two months, ~5,000 apps deployed.

### [cloud-decentralization] Every layer of the cloud stack is decentralizing
> "Every part of the cloud stack is getting decentralized, and we put all of them together into one umbrella called d-cloud, and Akash we're positioning as the gateway for the d-cloud."

**Context:** Explaining the "d-cloud" term Akash coined: compute (Akash), storage (Sia/Filecoin), DNS (Handshake), key management (NuCypher).

> "Anybody can go build a Supermini... it's just a GPU cluster. If you have a GPU cluster, when we have GPUs enabled on Akash you can plug in, earn money. Right now you can actually plug in any box, ideally sitting in a data center, to earn Akash token."

### [gpu-economics] The invisible Amazon tax on machine learning
