## Summary

A short clip (speaker is Greg — he describes meeting Solana's Anatoly Yakovenko in early 2018 and calls him "a good friend of mine," matching Greg's known Solana testimonial) on composability across IBC-enabled protocols. With deeper Solana-Akash integration, he sketches a division of labor between edge devices and decentralized cloud: phones are lightweight devices, so do light processing on the phone and heavyweight processing on Akash — "the mobile operating system can work in tandem with the cloud operating system... without the user even knowing about it." Example: cloud-rendered high-end game graphics streamed to mobile. Add Helium's upcoming 5G network and "you can see a future where Akash, Helium and Solana work in tandem to deliver a user experience on a mobile device that has never been done before" — possible within a year once IBC lands on Helium and Solana. He's "particularly very excited for Solana Mobile."

## Predictions & Notable Claims

### [local-compute] Phones do light compute; Akash does the heavy lifting
> "Mobile phones are lightweight devices — they can [not] do the computations, right? So a use case for Akash there would be lightweight processing on the mobile phone and heavyweight processing on Akash, on a decentralized cloud. So you can see how the mobile operating system can work in tandem with the cloud operating system in a highly composable way, without the user even knowing about it. Such use cases could be like games... you can have the high-end graphic processing done on the cloud on Akash and deliver that directly to the mobile phone."
> — [00:00:42](https://www.youtube.com/watch?v=rpARsQQOLyU&t=42s)

**Context:** Early articulation of his edge-device-plus-decentralized-cloud split, prompted by Solana Mobile (Saga) plans.
