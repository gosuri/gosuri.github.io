## Summary

A screencast demo by a Praetor App developer (not Greg) showing Praetor version 0.2 simplifying Akash provider onboarding: connecting a wallet, adding host credentials, automated k3s setup (~2-5 minutes), on-chain provider creation, DNS/port configuration, optional audit application, and finally deploying a game to the newly created provider to prove it works end to end. Pitch: "you don't need any CLI knowledge" to become an Akash provider.
