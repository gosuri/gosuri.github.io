## Summary

Official Akash Network livestream ahead of the Mainnet 2 launch, with Greg (CEO), co-founder/CTO Adam Bozanich, and marketing manager Michael. Mainnet 2 is framed as the first real release of the platform — the "MVP" completing the whitepaper: the decentralized cloud marketplace with reverse auctions, flexible bid pricing, mTLS authentication with on-chain certificates, escrow accounts, audited attributes, and IBC compatibility (Akash claiming to be among the first Stargate/IBC-enabled Cosmos chains). Greg pitches Akash as an answer to cloud centralization ("controlled by four companies") and, referencing that morning's AWS outage that hit Binance and FTX, as a disaster-recovery/failover alternative with 2–3x price advantages. He explains the Cosmos sovereign-chain security-budget model versus Ethereum's shared-cost model, predicts early adoption from DeFi front-ends, developer tooling, block explorers, and Cosmos sentry nodes ("climbing the credibility ladder"), and describes the long-term "holy grail" of open, permissionless managed services completing a "serverless supercloud." Notable dated specifics: Mainnet 2 targeted for March 8, 2021; an Equinix partnership teased as "an open secret" to be announced "next week" with Equinix as Akash's first big enterprise user; AKT all-time high of $3.50; 2M blocks; 93% governance turnout. Adam demos the new deploy tool but the live demo fails because engineers were mid-upgrade on the test network. The stream ends with community Q&A (validators, security, use cases), merch giveaways, and a Ledger Nano X drawing.

## Predictions & Notable Claims

### [cloud-decentralization] Breaking the four-company cloud oligopoly
> "The cloud, which is the foundational fabric of modern society... is increasingly becoming centralized, controlled by four companies. Number one thing Akash addresses is breaking this oligopoly and giving cloud back to the people."
> — [00:02:48](https://www.youtube.com/watch?v=fUeDGAt7IUk&t=168s)

**Context:** Answer to "what need does Akash's decentralized cloud marketplace address"; his foundational recurring thesis. (Captions render "cloud" as "clout.")

### [cloud-decentralization] The cloud's promise is a false premise — outages prove it
> "Cloud gives you this false premise that, hey, it's ultimately scalable — put all your eggs in one basket and we'll take care of everything. And what happened today, this morning: Binance went down, FTX went down, because they all trusted Amazon is the panacea... it's just false. These things keep going down over and over and again."
> — [00:04:57](https://www.youtube.com/watch?v=fUeDGAt7IUk&t=297s)

**Context:** A major AWS outage that morning had disrupted crypto exchanges; he positions Akash as a disaster-recovery/failover site since "you can't keep your eggs in one single basket."

### [cloud-decentralization] 2–3x price advantage from market-driven pricing
> "2x to 3x, in some cases much higher, price advantage compared to the current market."
> — [00:04:14](https://www.youtube.com/watch?v=fUeDGAt7IUk&t=254s)

**Context:** Because Akash uses a market-driven reverse-auction model where "the user sets the price instead of the companies" (00:03:31).

### [crypto-depin] IBC/Stargate is a paradigm shift in how blockchains communicate
> "What Stargate brings to the table is the interoperability while having that highly decentralized and distributed security model, so I think this is a paradigm shift in how blockchains communicate today."
> — [00:11:21](https://www.youtube.com/watch?v=fUeDGAt7IUk&t=681s)

**Context:** He calls IBC "Ethereum-level interoperability without the cost" (00:10:39), contrasting Cosmos sovereign security budgets with Ethereum's shared gas costs, and says Akash will be the first chain to upgrade to Stargate connectivity.

### [cloud-decentralization] Akash as the gateway for decentralized cloud
> "It positions Akash as the gateway for decentralized cloud... if you want storage — Akash doesn't do storage, Akash does compute — long-term storage on Filecoin or Sia coin or Arweave can be used via IBC."
> — [00:09:56](https://www.youtube.com/watch?v=fUeDGAt7IUk&t=596s)

**Context:** Vision of composable web3 infrastructure where compute, storage, and DNS interoperate across chains.

### [cloud-decentralization] Adoption will climb a credibility ladder, starting with DeFi front-ends
> "Getting to trust a platform is climbing the credibility ladder. As we prove ourselves that this is a viable alternative, we're going to see a lot more workloads. I think right off the bat we're going to see a ton of decentralized finance front-ends using Akash... a lot of developer tooling... a lot of block explorers and ecosystem tooling."
> — [00:35:17](https://www.youtube.com/watch?v=fUeDGAt7IUk&t=2117s)

**Context:** Asked about expected customer segments; he also predicts heavy Cosmos sentry-node usage and says start with non-mission-critical workloads like CI servers.

### [cloud-decentralization] Holy grail: managed services and a serverless supercloud
> "The holy grail eventually is to support managed services, and we're working towards it... we want to do so in an open source and in a permissionless manner like what we do with Akash... it'll be great to actually have your database managed by an expert versus self-managing your database."
> — [00:37:23](https://www.youtube.com/watch?v=fUeDGAt7IUk&t=2243s)

**Context:** He completes the thought as "the whole holy vision for a serverless supercloud that is fully open source and fully decentralized" (00:38:06) — an early on-record use of the supercloud framing.

### [other] Equinix teased as Akash's first big enterprise user
> "Our biggest big enterprise that we'll be announcing very soon, probably next week, is Equinix — I mean, it's an open secret at this point. So Equinix is the largest data center network in the world..."
> — [00:38:06](https://www.youtube.com/watch?v=fUeDGAt7IUk&t=2286s)

**Context:** Dated claim: Equinix would be "the first user of Akash," using it to offer computing services; earlier (00:28:08) he claims Akash runs on Equinix bare metal, "Amazon uses Equinix, so guarantee you're gonna have more security than Amazon."

### [other] Mainnet 2 launch targeted for March 8, 2021
> "We are currently aiming for March 8th, 2021, for the mainnet to be ready and accessible... if all goes well, March 8th is what we're looking at for Mainnet 2."
> — [00:21:17](https://www.youtube.com/watch?v=fUeDGAt7IUk&t=1277s)

**Context:** Following a 93% validator readiness vote and a ~14-day upgrade window; useful timestamped launch-date commitment.
