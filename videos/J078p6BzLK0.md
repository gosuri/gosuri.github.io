## Summary

An "Ask Akash" Q&A clip answering whether AWS or Hetzner could shut down Akash Network. The speaker (uncredited; consistent with Greg's voice in this series) admits surprise at a report that most Akash validator nodes were running on Hetzner — "I would imagine if you're an Akash validator you would not be running on a centralized [provider]" — and, given Hetzner's announced crypto ban, says validators should move to bare metal or colocated data centers. Interestingly, he argues validators should NOT run their full nodes on Akash itself: that would be a "meta deployment" — if the chain breaks, validators would be fixing the chain their node runs on, creating "all kinds of unknown problems" (ancillary infra like RPC nodes on Akash is fine). He concludes the validator set is permissionless and decentralized but the Nakamoto coefficient needs improvement: the top validator (Overclock Labs) had ~15 million AKT delegated versus ~77,000 for the smallest, so he encourages delegating to smaller validators.
